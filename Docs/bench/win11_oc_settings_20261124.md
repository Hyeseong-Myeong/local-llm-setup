## 시스템
- 튜닝 제어: 자동 오버클럭됨 (기본값 아님)

## CPU (Ryzen 5 5600X)
- 자동 튜닝: CPU 오버클럭됨
- Overclock Offset: +0.2 GHz
- 유휴 시 표시값: 2.2 GHz / 1.2 V / 23.9 W / 42.5 °C

## GPU (RX 6600 XT)
- 자동 튜닝: GPU 오버클럭됨 (VRAM 오버클럭 옵션은 선택되지 않음)
- 표시된 클럭 설정: +2646 MHz (유휴 시 현재 클럭 35 MHz)
- VRAM 클럭: 유휴 시 76 MHz 표시, VRAM 오버클럭 프리셋 미적용
- 유휴 시 표시값: 668 mV / 4 W / 34 °C / 팬 805 RPM

## 기타
- AMD SmartAccess Memory: 비활성화됨

## VRAM 오버클럭 적용 후 (2차 측정, win11_vramoc_20261124.csv)
- 사용자 보고: VRAM +2380 MHz 설정 (AMD Software 표시 기준, 기본값 대비 상승폭은 미확인)
- 1차 시도: 모델 2개 완료 후 비정상 종료 (Kernel-Power 41, WHEA 18 치명적 하드웨어 오류, 덤프 없음). 부분 결과는 win11_vramoc_crashed_partial_20261124.csv
- 재시도: 재부팅 없이 전 모델 완료, 새 WHEA 이벤트 없음
- 생성 속도: 기본 대비 GPU 전량 적재 모델 +8~11%, deepseek-r1:14b +3.3%
- 같은 시점에 CPU 자동 오버클럭(+0.2 GHz)도 켜져 있어 크래시 원인 분리 안 됨

## 측정 결과 요약 (GPU 코어 오버클럭 단계)
- 생성 속도 변화: 오버클럭 전 Windows 11 대비 +0.0~+0.7% (측정 오차 범위)
- 해석: VRAM 클럭을 올리지 않아 메모리 대역폭이 그대로였고, 토큰 생성 속도는 대역폭이 정함
